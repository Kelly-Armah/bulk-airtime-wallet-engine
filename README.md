## how to run and test my project

1. run npm i to install all dependencies

2. run  npm run start:dev to compile and set on watchmode

3. you can test the app on Postman or use Swagger http://localhost:3000/api/#/Transaction/TransactionController_uploadCsv

4. use the http://localhost:3000/transaction/upload url to test the app

5. you need to parse two params, the CSV file and the userId
